# 08. 원논문의 방법을 송도·독일 자료에 맞추어 분석 설계로 옮기기

기록일: 2026-09-16. 상태: **자료·원문 대조를 마친 분석 설계 초안**. 연구질문·가설·상충유형의 최종 확정이나 분석 결과가 아니다.

## 이 단계에서 무엇을 진행했는가

사용자는 GitHub를 기획 참고자료로 삼고 우리 자료에 맞춰 새로 작성하는 판단에 동의했다. 따라서 기존 코드의 실행 대신, **무엇을 한 사건으로 볼지 → TTC/PET를 어떻게 계산할지 → EVT로 무엇을 추정할지 → 무엇으로 검증할지**를 연결했다.

M1·M2 EN 원문을 사건 정의와 EVT·검증으로 나누어 재확인했다. 송도 제작 논문의 §3.7과 배포 README, 실제 궤적·차로지도 CSV 헤더, inD·rounD 공식 형식 문서를 대조했다. 후속 연구와 관련 연구도 확인하여 이미 수행된 비교를 새 연구 공백으로 쓰지 않았다. 원자료 분석·상충 추출·EVT 적합은 실행하지 않았고, 삭제한 노트북이나 참고 저장소의 코드를 가져오지 않았다.

**이번에 구체화한 판단:** 송도에는 사건을 구성할 위치·시각·지도 자료가 있다. 다만 사건표가 완성되어 있는 것은 아니다. 특히 송도의 중심좌표를 M2 식에 그대로 넣는 것, 후미추돌과 교차상충에 같은 PET 계산을 사용하는 것, 두 지표가 모두 극단인 사건만 남기는 것은 피해야 한다.

## 1. 유지하는 방향과 이번 설계의 범위

| 구분 | 현재 처리 | 이유 |
|---|---|---|
| 연구의 큰 틀 | 교통상충 TTC/PET의 단변량·이변량 EVT 비교 유지 | 사용자가 선택한 GitHub 기획의 출발점 |
| 주자료 | 송도 전체 800개 궤적 CSV를 입력 대상으로 설계 | 일부 지점 예비분석을 먼저 반복하지 않겠다는 사용자 지시 |
| 사건의 범위 | 차량–차량 후미추돌·교차상호작용을 구분하여 구성 가능성 확인 | 두 유형 중 하나를 지금 임의로 확정하지 않음 |
| 독일 자료 | 송도에서 정의한 사건에 대응하는 외부검증 자료로 검토 | 국가 간 안전수준 순위를 비교하는 연구로 바꾸지 않음 |
| 구현 | 합의한 정의에 따라 새 `.ipynb` 작성, 사용자가 실행 | 과거 분석 코드·출력 재사용 금지 |
| 차별점 | 원문 적용과 데이터 확장만으로 확보됐다고 주장하지 않음 | 후속 연구와 실제 분석이 추가로 확인할 질문을 연결해야 함 |

전체 자료를 본다는 것은 모든 차량쌍을 상충으로 인정하거나 서로 다른 유형을 한 모형에 섞는다는 뜻이 아니다. 전수 처리 후 대상·제외·정의불가의 수와 이유를 기록한다. 그림을 확인할 때 일부 사례를 보는 것은 전체 입력 범위를 줄이는 예비분석과 구분한다.

## 3. 우리 자료의 어떤 변수를 사용할 것인가

| 분석에 필요한 것 | 송도에서 제공하는 것 | inD·rounD에서 제공하는 것 | 처리 원칙 |
|---|---|---|---|
| 개체 식별 | 파일명 + `Vehicle_ID`, 출처 `Drone_ID` | 자료명 + `recordingId` + `trackId` | 파일·recording을 넘겨 ID가 같다고 연결하지 않음. 송도 ID는 CSV 안에서 고유하므로 Drone_ID를 임의의 별도 차량 판정 기준으로 삼지 않음 |
| 공통 시간축 | 파일 날짜 + `Local_Time` | `frame`과 `frameRate` | 행 번호·각 차량의 등장 후 경과시간으로 차량쌍을 맞추지 않음 |
| 차량 중심 위치 | `Local_X/Local_Y`, EPSG:5186, m | `xCenter/yCenter`, local UTM, m | 거리 계산은 m 좌표. 서로 다른 나라의 좌표를 한 좌표계로 합칠 필요는 없음 |
| 속력·속도벡터 | `Vehicle_Speed`는 km/h의 속력. heading·vx/vy 없음 | `xVelocity/yVelocity` m/s, heading degree | 송도 TTC용 방향·벡터는 위치·시간에서 구성해야 함. 독일과 단위·운동 가정을 맞춤 |
| 차량 크기 | 길이·폭 추정치, 일부 결측 가능 | 길이·폭, 객체 종류별 제공 특성 확인 필요 | 중심 간 거리를 그대로 범퍼 간 거리로 사용하지 않음 |
| 이동 경로 | `Road_Section/Lane_Number`와 차로 다각형·정사영상 | 지도와 궤적, tracks에 선행차·차로 ID 없음 | 전후 구역과 궤적을 연결하여 이동류와 차량 관계를 구성 |
| 교차로 중앙 | 구역·차로 라벨이 없을 수 있음 | 지도 연결부와 궤적을 사용 | 무라벨이라는 이유로 회전 중 궤적을 삭제하지 않음 |
| 신호·사고 정답 | 제공 열에 신호현시·사고기록 없음 | 제공 열에 해당 시점 신호현시·사고 정답 없음 | 궤적만으로 보호/비보호 신호나 실제 사고 대조가 확보됐다고 주장하지 않음 |

송도 제작자는 위치 궤적 자체에는 평활·보간을 적용하지 않고, 제공 속력·가속도는 검색을 돕기 위한 보간·평활 추정치라고 설명한다. 따라서 이 속력을 상세 TTC 계산에 그대로 사용하는 것은 별도 타당성 검토가 필요하다. 위치 기반 속도벡터 추정의 시간창과 평활 강도는 문헌 및 궤적 오차 확인을 거쳐 정하며, 이번 기록에서 임의 숫자를 고정하지 않았다. 속력 단위 변환은 `m/s = km/h ÷ 3.6`이다.

## 4. 무엇을 ‘한 사건’으로 볼 것인가

이 절은 **우리 자료에 기존 방법을 적용하기 위한 검토 초안**이다. 새로운 수식·상충 판정법을 개발하려는 것이 아니다. M1·M2에 세부 절차가 없다면 원논문이 인용한 방법과 관련 연구에서 적용조건을 확인하여 채택한다. M1·M2에 완전히 같은 알고리즘이 적혀 있다는 뜻도 아니다.

### 먼저 상호작용 후보를 구성한다

1. 송도 전체 파일을 처리하되, 파일·차량 ID·시각·원래 행 출처를 보존한다. 서로 다른 관측 조각이나 드론의 중복 의심 궤적을 확인 없이 하나로 잇지 않는다.
2. 진입·진출 구역과 실제 이동 경로로 차량의 이동류를 구분한다. 식별 근거가 부족하면 미분류로 남긴다. `Road_Section` 숫자만으로 동서남북이나 회전 방향을 정하지 않는다.
3. 후미추돌 후보는 **동일 주행 경로에서 실제로 연속된 선행차–후행차**로 구성한다. 단순히 가까운 두 차량이나 옆 차로 차량을 앞차로 선택하지 않는다.
4. 교차 후보는 **경로가 같은 지점 또는 작은 공간을 가로질러 통과하는 차량쌍**으로 구성한다. 경로가 만나는 것과 현재 운동을 유지하면 실제로 충돌하는 것은 구분한다. PET는 두 차량의 동시 점유가 없어도 정의될 수 있으므로 같은 프레임의 근접 여부만으로 후보를 제한하지 않는다.
5. 같은 차량쌍이라도 분리된 이동·재접근은 별도 사건이 될 수 있다. 사건은 차량쌍·이동류·연속된 상호작용 구간을 함께 식별한다. 긴 관측 공백을 보간으로 메우거나 원안의 ‘3초’를 근거 없이 분리 기준으로 고정하지 않는다.
6. 후보별로 지표를 계산하고, 그다음 극단표본을 선정한다. 후보 추출 때부터 TTC/PET가 모두 작다는 조건을 걸지 않는다.

이때 후보 수, 지표 계산 가능 사건 수, EVT 임계값 초과 사건 수는 서로 다르다. 결과 표에서도 모두 ‘상충 건수’라는 같은 이름으로 부르지 않는다. 후보 선정의 공간·시간 범위가 제한된다면 그 범위와 놓칠 수 있는 사건을 함께 기록한다.

### 사건표에서 보존할 항목

| 묶음 | 주요 항목 |
|---|---|
| 출처·개체 | 자료·지점·날짜·파일/recording·차량쌍 ID·원자료 위치 |
| 상황 | 후보 상충유형·두 차량 이동류·선후 관계·사건 시작/종료 |
| 공간 정의 | 경로·교차점/영역/선 ID와 버전·차체 기준 |
| 지표 | minTTC·PET 또는 minPET·각 대표값 발생 시각·계산법 버전 |
| 계산 상태 | 각 지표의 유효·충돌 경로 없음·통과 관측 부족·크기/방향 부족·품질 의심 등 |
| 선정·검증 | 포함/제외 사유·EVT 꼬리 선택 여부·자료 분할 단위·확인 결과 |

두 지표의 사건 대표값이 같은 프레임에 발생해야 한다는 조건은 추가하지 않는다. 사건별 대표값을 결합한다는 뜻과 동일 순간의 물리적 위험을 측정한다는 뜻은 다르다.

2026-09-17 원문 재확인: 위 표는 **사건 단위 입력 기록**이다. EVT에 넣는 최종 표본 단위까지 사건으로 고정한 것이 아니다. M1의 BGEV는 지표별 블록 극값을 결합하므로 같은 블록의 TTC와 PET 극값이 서로 다른 사건에서 나올 수 있다(§3.2, PDF3–4/인쇄213–214). M1의 BGP에서는 지표쌍과 꼬리 비초과의 검열 정보를 다룬다(§5.2, PDF8–9/인쇄218–219). 사건표에서 BM 또는 POT 표본을 만드는 규칙과 각 확률의 분모를 별도로 명세해야 한다. 이 구분을 새 연구 차별점으로 제안하거나 BM/POT 선택으로 확정하지 않는다.

## 5. TTC·PET 계산을 어떻게 자료에 맞출 것인가

### 후미추돌 TTC: 중심좌표에서 실제 차간 간격으로

M2 식(1)은 `(x_L - x_F - D_L) / (v_F - v_L)`이며, 원문은 x의 앞범퍼/중심 기준을 명시하지 않는다. 송도와 inD·rounD는 중심좌표를 제공하므로 그대로 대입하지 않는다.

**같은 직선 경로에 정렬된 차량**이라면 중심의 경로상 위치를 `s_L, s_F`, 차량 길이를 `L_L, L_F`라 할 때 우리 좌표에 맞춘 기하학적 표현은 다음과 같다.

`s`는 두 차량이 공유하는 직선의 진행 방향으로 증가하는 중심 위치이며, `v_L, v_F`는 같은 방향의 속도성분(m/s)이다. 두 차량의 위치·길이·속도는 같은 시각에 대응시킨다.

\[
g=(s_L-L_L/2)-(s_F+L_F/2),\qquad
TTC=\frac{g}{v_F-v_L}\quad(g>0,\ v_F>v_L).
\]

쉽게 말해, **앞차의 뒤끝과 뒤차의 앞끝 사이 빈 거리**를 두 차량이 가까워지는 속도로 나눈다. 이는 중심좌표에 대한 변환 설명이며 M2의 원문 표기를 그대로 옮긴 식은 아니다. 곡선·차로 변경·횡방향 어긋남에서는 이 직선 가정을 적용할 수 있는지 확인하고, 같은 식으로 강제 계산하지 않는다. `g≤0`도 겹침·추정오차를 확인하기 전 실제 사고로 판정하지 않는다.

### 교차상충 TTC: 가까워지는 시간과 충돌시간을 구분

M1의 정의인 **현재 속도·방향을 유지할 때 충돌까지 남은 시간**을 따른다. 이를 중심좌표 궤적에 구현하기 위한 우리 후보안은 두 차량의 차체 영역이 처음 겹치는 양의 시간을 계산하는 것이다. 이 차체 기하 알고리즘은 M1 본문에 완전하게 제시되어 있지 않다. 중심점이 가장 가까워지는 시각(CPA), 교차점에 한 차량이 도착하는 시각, 실제 차체의 충돌 시각은 같은 값이 아니다.

차체 형상, 방향 추정, 예측 시간 범위와 회전 중 운동 가정은 추가 구현 명세가 필요하다. ‘정속·현재 방향 유지’와 ‘관측된 미래 회전 경로를 미리 사용’도 서로 다른 지표다. 원논문 정의를 따른 TTC와 다른 가정의 확장 지표를 같은 이름으로 섞지 않는다. 이 기하 구현을 GitHub 코드에서 가져오거나 현재 확정된 것으로 기록하지 않는다.

### PET: 같은 공간을 실제로 통과한 간격

\[
PET=t_{\mathrm{두번째\ 차량\ 진입}}-t_{\mathrm{첫번째\ 차량\ 이탈}}.
\]

- **교차상충:** 해당 이동류의 교차점 또는 명시한 충돌 공간에서 실제 통과 시각을 사용한다. 교차로 전체를 한 영역으로 잡으면 서로 떨어진 곳을 지나간 차량까지 같은 공간의 사건으로 오인할 수 있다.
- **후미추돌:** M2의 conflict/encroachment line 정의를 따르되, 고정 횡단선 하나의 측정으로 단순화하지 않는다. 직접 인용된 Gettman & Head2003의 conflict line은 앞뒤 차량의 공통 주행 공간이며 여러 위치에서 평가한 PET의 사건 최솟값을 설명한다. 차간거리/속력이나 중심점 THW로 자동 대체하지 않는다.
- 지점 통과와 차체 영역 점유는 다른 기하 선택이다. 어떤 공간과 차량 경계를 사용했는지 저장한다. M2의 실제 PET 평가 위치·통과시각 계산·사건 경계 세부 구현은 여전히 추가 확인 항목이다. 2003 보고서의 수식·시각 기호를 통째로 이식하지 않으며, 보충 근거와 한계는 [11 기록](11_원논문에서차량쌍과사건구성으로.md)에 남겼다.
- 2026-09-17 후방 인용 확인: M1이 직접 인용한 Ismail2010의 저자 원고에는 점·궤적 교점 방식이 있다. 이로부터 M1 자체의 형상을 단정하지 않는다. M3가 인용한 Laureshyn2010과 관련 학위논문은 차체 기하를 보충할 수 있는 별도 근거다. 차체 방식은 구현 후보이며 M1의 확인된 알고리즘이라는 뜻이 아니다.
- 진입·이탈이 관측되지 않았다면 추측한 PET를 만들지 않는다. 겹치는 점유나 음수 차이는 별도 상태로 기록하고, 임의 절댓값·0으로 바꾸지 않는다.

### 정의불가와 검열은 다르다

| 상태 | 의미 | 처리 |
|---|---|---|
| 유효하지만 덜 극단적 | 값은 계산됐고 EVT 임계값을 넘지 않음 | 선택한 모형의 비초과·검열 정보로 사용 가능 |
| 충돌 경로 없음 | 현재 운동으로 충돌하지 않아 유한 TTC가 없음 | 별도 구조적 상태. PET까지 삭제하거나 TTC=0으로 입력하지 않음 |
| 자료 부족 | 궤적·크기·방향·통과시각 등이 부족 | 관측/계산 결측으로 표시 |
| 품질 의심 | 비현실적 변화·차체 겹침 등 | 확인 및 제외 여부와 이유 기록 |

원논문의 검열우도를 사용한다는 사실만으로 정의불가·결측을 비초과로 처리할 수는 없다. 두 지표가 모두 유효한 사건만 선택하는 진단을 하더라도 그 조건으로 분석 대상이 좁아졌음을 명시한다.

## 6. EVT로 무엇을 추정할 것인가

### 부호·임계값·경계를 구분한다

사건 대표값을 `X = −minTTC`, `Y = −PET`로 변환한다. M2의 정의를 쓰는 후미추돌에서는 `Y = −minPET`가 된다. 각 지표가 0초에 가까울수록 변환값은 커진다. 역수나 임의 epsilon은 도입하지 않는다.

| 기준 | 역할 |
|---|---|
| 후보 선정 기준 | 어떤 상호작용을 조사할지 정함 |
| 상충 판정 기준 | 특정 값 이하를 위험 사건으로 분류하는 운영상 기준 |
| EVT 꼬리 임계값 u | 극단분포를 적합할 표본 범위를 정함 |
| 0초 경계 | 원논문에서 사고 쪽으로 외삽할 때 사용한 지표 경계 |

따라서 연구배경은 ‘EVT로 임계값을 없앤다’가 아니라, **고정 기준으로 사건 수만 세는 접근에서 극단 영역의 분포를 추정하는 접근으로 확장한다**고 설명한다. POT에도 임계값 선택과 진단이 필요하다.

단변량 POT의 첫 비교 후보는 각 지표의 임계값 초과량에 대한 GPD다. 유효한 사건 모집단을 명시하고 `X>u`, `z=X-u≥0`라 두면 꼬리 생존확률의 형태는 다음과 같다.

\[
P(X>u+z\mid X>u)\approx
\left(1+\xi z/\sigma\right)^{-1/\xi},\quad
\sigma>0,\quad 1+\xi z/\sigma>0.
\]

`ξ=0`에서는 `exp(−z/σ)`를 사용한다. 이것은 **이미 꼬리에 들어온 사건 중에서의 조건부 확률**이다. 전체 대상 사건의 확률을 구하려면 `P(X>u)`를 별도로 연결한다. 시간당 발생수로 바꾸려면 그 대상 사건의 발생률까지 필요하다. 확률에 시간만 곱해 사고건수라고 부르지 않는다. 분포의 지지범위를 벗어난 경계에 수식을 기계적으로 적용하지 않는다.

임계값은 평균초과량·모수 안정성·적합도·불확실성을 함께 보고 판단한다. 원안의 상위 90/95/97.5%나 꼬리 30개를 충분성의 정답으로 고정하지 않는다. 사건별 한 값으로 줄여도 같은 차량·교통 흐름을 공유하는 사건들의 독립성이 자동 보장되지는 않는다.

### 공동모형은 ‘두 지표가 모두 작다’와 같지 않다

M1·M2에서 사용하는 공동 사고경계 표현은 `X≥0 또는 Y≥0`에 해당한다. 연속분포를 가정하면 경계에서의 등호 유무는 확률을 바꾸지 않는다. 결합분포를 F라고 할 때 수학적으로 다음 두 확률은 다르다.

\[
P(X>x\;\mathrm{or}\;Y>y)=1-F(x,y),
\]
\[
P(X>x\;\mathrm{and}\;Y>y)=1-F_X(x)-F_Y(y)+F(x,y).
\]

M1·M2의 원문 경계를 따르는 경우 `x=y=0`이며, 이를 AND 확률로 바꾸면 다른 추정 대상이 된다. POT 적합에서는 해당 F가 어떤 선정·조건부 표본에 관한 분포인지까지 명시해야 한다. 0초를 넘는 모형 꼬리는 사고 쪽으로의 외삽이며, 실제 사고가 관측됐다는 의미가 아니다.

M2 pp.4–5는 각 지표의 초과·비초과에 따라 네 영역을 구분한 검열우도를 설명한다. 한쪽만 초과한 사건을 버리고 두 지표가 모두 극단인 사건만 적합하는 것은 같은 방법이 아니다. 원문 이변량 GP/GEV와 GitHub의 일반 copula 후보를 동일한 모형으로 간주하지 않는다. 첫 모형 명세는 M1·M2의 분포·우도·추정대상을 대조해 구성한다.

원안의 ‘의존성이 약하면 공동모형 포기’도 자동 규칙으로 사용하지 않는다. 전체 상관, 극단모형의 의존 모수, 꼬리의존계수는 구분해야 한다. 어느 모형이 더 낫다는 결론은 공통 평가 대상과 불확실성에 근거해야 한다.

## 7. 무엇으로 결과를 검증할 것인가

현재 확보한 것은 궤적자료이지 M1·M2처럼 해당 상충유형에 맞춰 대조할 사고기록은 아니다. 아래 평가들을 구분해서 설계한다.

| 확인할 것 | 대조할 자료·방법 | 주장할 수 있는 범위 |
|---|---|---|
| 사건·지표가 의도대로 계산됐는가 | 정사영상 위 두 차량 궤적, 이동류·차체 간격·통과 순서, 정의불가 상태 확인 | 상충 추출과 지표 계산의 타당성 |
| 관측된 꼬리분포를 설명하는가 | 임계값 진단·QQ/PP·불확실성 및 정의된 표본 범위의 경험적 초과확률 | 관측 가능한 상충 꼬리 영역의 적합성 |
| 별도 자료에도 적용되는가 | 같은 사건 정의를 적용한 보류 recording/지점 및 대응 가능한 독일 사건 | 정해진 범위에서의 외부 적용·평가 |
| 실제 사고빈도를 잘 추정하는가 | 동일 위치·상충/사고유형·대상 교통·기간 조건을 맞춘 사고기록 | 이 대조가 확보된 범위의 사고빈도 추정 성능 |

**비교를 위한 조건:** TTC만의 확률, PET만의 확률, OR 또는 AND의 공동확률은 서로 다른 대상이다. 같은 정답을 예측하는 모형끼리 비교하도록 결과 변수와 분모를 먼저 정한다. 단변량 AIC와 이변량 AIC, 서로 다른 표본의 우도, 다른 지표의 오차를 숫자 크기만으로 비교하지 않는다. 두 단변량을 독립으로 결합한 기준모형도 독립이라는 추가 가정이며 단변량 하나와 같은 것은 아니다.

자료를 나눌 때 같은 사건의 프레임을 학습·평가에 나누지 않는다. 전처리·임계값·모형 선택에 쓴 자료와 외부 평가 자료의 역할을 구분한다. 정확한 분할 단위와 반복 평가 방법은 사건표의 차량 공유·기록 구조를 확인하여 정한다. 독일 자료에서 모형을 다시 적합한 비교와 송도에서 정한 모형을 고정한 평가도 구분하며, 후자를 지점 간 모수 전이 연구로 자동 확대하지 않는다.

**현재 보류:** 사고기록 없이 단변량과 이변량 중 어느 쪽이 실제 사고를 더 정확히 예측하는지 확정하는 가설. 사고자료를 꼭 써야 한다고 지금 결정하지도 않는다. 관측 가능한 영역의 검증만으로 논문을 구성할 경우에는 그 평가와 기여가 충분한지 후속 연구와 함께 판단해야 한다.

## 8. 독일 자료를 어떻게 연결할 것인가

- **교차상충을 중심으로 정하면 inD부터 대응성을 검토한다.** 중심 위치·속도벡터·heading·지도를 제공한다. 다만 inD의 비신호 교차로를 송도의 신호교차로와 같은 운영 조건으로 취급하지 않는다.
- **rounD는 회전교차로다.** 진입–순환 등 다른 이동 관계가 포함되므로, 송도 사건 정의와 실제로 비교 가능한 경우에만 별도 적용 범위를 설정한다. inD와 동등한 자동 대체 자료가 아니다.
- 후미추돌 사건도 구성할 수 있지만, 어느 독일 자료를 쓸지는 송도에서 선택한 시설·차량 관계에 맞춰 정한다. highD/exiD를 보유했다는 이유만으로 연구 대상을 고속도로로 바꾸지 않는다.
- 두 자료의 좌표·단위·지표 계산 정의는 맞추되, 서로 다른 교통 운영 조건과 사건 구성 비율을 지우지 않는다. 양국 전체의 안전수준 비교로 일반화하지 않는다.

자료별 세부 구조와 공식 출처는 [07 기록](07_자료구조의이해와분석단위정리.md)에 있다. 이번 단계는 그 구조를 재조사하는 단계가 아니라 실제 분석 정의에 연결하는 단계다.

| [Jiao et al. (2025)](https://doi.org/10.1016/j.amar.2024.100369), 로컬 S02 PDF pp.2·15 | 상호작용 맥락에 따른 확률적 상충 정의. 실증은 고속도로 차로 변경·추종 등의 공간 근접성 중심 | 고정 기준 문제에서 확률적 정의로 나아가는 접근도 이미 있음. 이를 우리 TTC/PET 모델과 같은 방법으로 간주하거나 바로 추가 구현하지 않음 |

Jiao는 2024-12 온라인 공개, 학술지 권호는 2025년이다. 로컬 표지의 2024와 본문의 2025를 별개 연구로 중복 세지 않는다. Niu는 이번 검토에서 출판사 검색 정보와 [저자 Tarek Sayed가 공개한 동일 논문 전문](https://www.researchgate.net/publication/383849570_A_cross-comparison_of_different_extreme_value_modeling_techniques_for_traffic_conflict-based_crash_risk_estimation)을 대조했다. M3의 역할은 기존 [02 기록](02_문헌검토와설계수정.md)과 같이 상충지표·적용 맥락의 배경을 설명하는 리뷰이며, EVT 구현서로 바꾸지 않는다.

**연구배경의 현재 연결:** 사고가 드물고 사후적으로 관측된다는 이유로 궤적 기반 상충지표를 사용한다 → 지표와 판정 기준에 따라 포착하는 사건이 달라진다 → EVT와 이변량 접근이 이미 발전해 왔다 → 우리 자료에서 어떤 사건·지표·추정 대상·검증 조건을 구성할 수 있는지 확인한다. 마지막 단계에서 확인할 질문이 기존 연구와 어떻게 다른지는 추가 근거가 필요하다. 이번의 구현상 보완사항들을 그 자체로 논문의 독창성이라고 주장하지 않는다.

## 10. 다음 구현에 넘길 내용과 남은 결정

다음 새 `.ipynb`는 전체 송도 입력에서 **이동류·차량 관계·사건표를 만드는 단계**로 구성한다. 이미 문서로 확인한 제작팀·촬영 구조를 다시 분석하는 노트북을 만들지 않는다.

| 순서 | 노트북에서 수행할 내용 | 실행 후 확인할 산출물 |
|---|---|---|
| 1 | 전체 파일의 공통 시각·중심좌표·출처를 정규화하고 이동류·경로를 연결 | 파일·지점별 처리 수, 미분류/관측 불완전 사유 |
| 2 | 후미추돌 연속 차량쌍과 교차 경로 차량쌍을 분리하여 사건 구성 | 유형별 사건표, 연결·분리 근거, 원자료 위 확인 그림 |
| 3 | 명세가 정해진 TTC/PET 계산과 상태 기록 | 유효 값뿐 아니라 정의불가·결측·품질 문제의 내역 |
| 4 | 분석 대상·추정 대상·검증 범위를 선택하고 EVT 입력 구성 | 표본 흐름표, 분포 진단, 모형별 입력 범위 |

순서 1부터 전체 파일을 입력 대상으로 삼는다. 단계별 결과에 따라 유형의 범위나 계산 규칙을 수정할 수 있으며, 좋은 결과가 나온 사례만 남기는 방식은 사용하지 않는다.

TTC/PET 및 사건 판정 코드를 작성하기 전에 더 구체화할 항목은 **송도 방향·속도벡터 추정법, 교차 TTC의 차체 충돌기하, PET 공간/선 배치, 사건 분리와 불완전 관측 처리**다. 새로운 수식이나 임의의 기준값으로 채우지 않고 원논문의 인용 방법 및 관련 연구에서 적용할 절차를 확인한다. 이 방법들이 필요하지 않은 제공 궤적·라벨의 시간순 정리는 먼저 구현할 수 있다. 최종 상충유형·가설·새 기여는 그 근거와 전체 사건 구성 결과를 함께 보고 좁힌다.

### 후속 진행: 입력 정리부터 실제 노트북으로 연결

사용자가 분석 방법을 설명하고 순차적으로 진행하도록 요청하여 [09. 전체 궤적에서 상충 분석의 입력 만들기](09_전체궤적에서상충분석의입력만들기.md)와 새 `01_송도_전체궤적_이동경로정리.ipynb`를 준비했다. 첫 단계는 이미 제공된 도로·차로 라벨과 위치·시각을 정리하는 작업이다. 차량쌍 사건 추출·TTC/PET 계산·모형 적합까지 완료했다는 뜻이 아니다. 이전의 촬영시간 예비분석을 복원하지 않는다.

### 다음 계산 단계에 사용할 문헌의 연결도 확인

M1 p.5는 이 연구에서 사용한 영상의 자동 상충 분석 세부 내용으로 **Tageldin, Sayed & Ismail (2018), Evaluating the Safety and Operational Impacts of Left-Turn Bay Extension at Signalized Intersections Using Automated Video Analysis**를 직접 가리킨다([DOI](https://doi.org/10.1016/j.aap.2018.07.029)). 이 인용 관계와 서지는 확인했지만 해당 논문의 세부 계산·사건 분리 명세는 이번에 전문 확인하지 않았다. Saunier & Sayed (2007·2008), Ismail et al. (2010)도 같은 문단의 자동 분석 계열 인용이며, 마지막 논문은 보행자–차량 대상이므로 적용 대상을 구분한다.

보유 S04 **Huang & Chen (2025), Estimating Intersections’ Near-Crash Conflicts With the Drone-Based Image-Recording Data**는 §2.3.1–2.3.3, PDF pp.3–4에서 직사각형 차체·상대속도를 이용하는 충돌 경로 식과 TTC 계산식, p.5 Fig.3에서 처리 절차를 제공한다([DOI](https://doi.org/10.55329/snjp4746)). 따라서 새 충돌기하 수식을 만들지 않고 대조할 기존 방법 후보가 있다. 다만 차종별 표준 크기라는 입력 가정, 회전 중 현재 방향 유지의 한계(p.14)를 확인해야 하며 **현재 채택한 것은 아니다**. PET의 세부 계산 명세는 이 문헌에서 not_found다. 또한 충돌 경로가 없는 차량쌍을 제외하는 S04 절차를 PET 후보 추출까지 적용하면 M1의 지표 범위가 달라지므로 전체 파이프라인의 대체재로 삼지 않는다.
